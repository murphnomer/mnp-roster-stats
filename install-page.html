MNP Roster Stats

Adds Points and POPS columns to any match's team roster page, so you can see how everyone's doing while the match is on.

Safari on iPhone or iPad

Quickest: the MNP Stats shortcut

Add the MNP Stats shortcut
  1. Tap the button above, then tap Add Shortcut.
  2. Open a team roster page, tap Share and choose MNP Stats. The first time, allow it to access mondaynightpinball.com.

It loads the latest version every time, so there's nothing to update. If it says running scripts isn't allowed, go to Settings → Apps → Shortcuts → Advanced and turn on Allow Running Scripts.

Or build the shortcut yourself
Quickest: build the MNP Stats shortcut
  1. Copy the shortcut code below.
  2. Open the Shortcuts app and tap + to start a new shortcut.
  3. Tap Search Actions, search for Run JavaScript on Webpage and add it.
  4. In that action, select all the sample code and paste the shortcut code over it.
  5. Tap ⓘ (or the name at the top → Details) and turn on Show in Share Sheet. If the action doesn't read "Run JavaScript on Shortcut Input", tap its web page field and choose Shortcut Input.
  6. Rename the shortcut MNP Stats and tap Done.
  7. To use it, open a team roster page, tap Share and choose MNP Stats.

Runs on its own: the Userscripts app

Install the free Userscripts app from the App Store and turn it on under Settings → Apps → Safari → Extensions. Then open the userscript in Safari, open the Userscripts extension menu and tap Install. After that the columns appear by themselves and the script updates itself.

Bookmarklet

A bookmark that adds the columns when you tap it. It loads the latest version every time, so you only set it up once.

MNP Stats

Save it in Chrome on Android

  1. Open any web page, tap ⋮ and tap the ☆ star to bookmark it.
  2. Tap ⋮ → Bookmarks, tap ⋮ next to the new bookmark and choose Edit.
  3. Rename it to MNP Stats. Clear the URL field, paste the code, and go back to save.

Save it in Chrome on iPhone or iPad

  1. Open any web page, tap ⋯ and choose Add to Bookmarks.
  2. Tap ⋯ → Bookmarks, press and hold the new bookmark and choose Edit Bookmark.
  3. Rename it to MNP Stats. Clear the URL field, paste the code, and tap Done.

In Safari, the shortcut is easier. Use to see it.

Save it on a computer

Drag the MNP Stats button to your bookmarks bar. If Chrome sync is on, it shows up on your phone too.

Use it

  1. Open a match and tap a team name to reach its roster (the address ends in /home or /away).
  2. Tap the address bar, type MNP Stats, and tap the bookmark in the suggestions. Opening it from the Bookmarks list doesn't run it.
  3. Click MNP Stats in your bookmarks bar.

Firefox on Android

Want it to run by itself, with no tapping? Firefox can do that.

  1. In Firefox, tap ⋮ → Extensions and add Violentmonkey or Tampermonkey.
  2. Open the userscript and tap Install.

The columns then appear on every roster page, and the script updates itself.

Runs on its own on a computer

Chrome, Edge or Firefox with a userscript manager

Install the Tampermonkey or Violentmonkey extension, then open the userscript and click Install. It updates itself.

Chrome without a userscript manager

Download the extension zip and unzip it. Go to chrome://extensions, turn on Developer mode, click Load unpacked and pick the unzipped folder.

How POPS is calculated

POPS is points earned divided by points available in the games a player has finished, shown as a decimal (0.750 means 75% of the available points). Each game is worth 2.5 points per player in rounds 1 and 4 (doubles) and 3 points in rounds 2 and 3 (singles). Games still in progress aren't counted.
